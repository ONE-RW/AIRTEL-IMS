## VIDEO RECORDING TIPS

### Technical Setup:
1. **Resolution**: Record at 1080p (1920x1080) or higher for clarity
2. **Frame Rate**: 30 FPS or 60 FPS for smooth motion
3. **Audio**: Use a quality microphone; avoid room noise
4. **Screen**: Set browser zoom to 100%, use clean desktop

### Recording Process:
- **Use screen recording software**: OBS Studio (free), Camtasia, or ScreenFlow
- **Record in two passes**: System audio (UI sounds) + voiceover (narration separately)
- **Demo data**: Use realistic but sanitized sample data (names, departments)
- **Pacing**: Pause between segments for smooth transitions
- **Backup**: Record extra footage of key features for editing flexibility

### Demo Flow Checklist:
- [ ] Employee creates request
- [ ] HR approves request
- [ ] IT Support reserves equipment
- [ ] Warehouse fulfills order
- [ ] Device assigned with QR code
- [ ] Equipment lifecycle view
- [ ] Return workflow
- [ ] Move order creation
- [ ] Analytics dashboard
- [ ] AI chatbot interaction
- [ ] Mobile responsiveness
- [ ] Audit logs

### Editing Suggestions:
- Add transition slides between segments
- Include text overlays for key statistics
- Highlight interactive elements with cursor effects
- Add background music (royalty-free)
- Include company branding in intro/outro
- Add captions for accessibility
- Total runtime: ~18-20 minutes
